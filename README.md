# React-Digi-Pet

React-based Digital Pet Browser Game

Windows / npm:

```powershell
npm install
npm run dev
# or
npm run build
npm run preview
```

## Deploying to GitHub Pages

In the repository's **Settings → Pages**, set the build and deployment source
to **GitHub Actions**. Pushing to `main` then builds the site with Vite and
deploys the generated `dist` directory. The workflow can also be started
manually from the **Actions** tab.
